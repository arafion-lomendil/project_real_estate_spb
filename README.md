В этом проекте при помощи SQL и Datalense проведено исследование агентства недвижимости из Петрозаводска, которое планирует выйти на рынок Санкт-Петербурга и Ленинградской области. Агенству нужен готовый анализ объявлений о продаже жилой недвижимости в Санкт-Петербурге и Ленинградской области, чтобы найти самые перспективные сегменты недвижимости.

Проект состоит из трех частей:
1. Знакомство с данными (код добавлю позже)
2. Решение ad-hoc задач:
- Определить наиболее привлекательные сегменты недвижимости Санкт-Петербурга и городов Ленинградской области, чтобы создать эффективную бизнес-стратегию на рынке недвижимости.
- Понять сезонные тенденции на рынке Санкт-Петербурга и городов Ленинградской области, чтобы знать периоды с повышенной активностью продавцов и покупателей недвижимости в регионе.
3. Создание дашборда для заказчика с основными показателями по рынку недвижимости Санкт-Петербурга и Ленинградской области.
